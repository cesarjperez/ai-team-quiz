# Cuestionario de Conceptos Fundamentales de IA

Una aplicación web interactiva diseñada para evaluar y repasar conceptos clave de inteligencia artificial por niveles (Fundamentos, MCP, Skills, RAG y Agentes Autónomos).

## Características
- **5 Niveles de Dificultad:** Desde arquitectura básica hasta tool calling y agentes autónomos.
- **Retroalimentación Instantánea:** Validación inmediata de respuestas correctas e incorrectas.
- **Sistema de Desbloqueo:** Avanza superando los niveles secuencialmente.
- **Diseño Moderno:** Interfaz oscura, limpia y responsiva lista para compartir.

## Cómo publicarlo en línea con GitHub Pages (Gratis en 2 minutos)
1. Crea un nuevo repositorio en [GitHub](https://github.com/new) con el nombre que prefieras (por ejemplo: `ai-team-quiz`).
2. Sube estos dos archivos al repositorio:
   - `index.html`
   - `README.md`
3. Ve a la pestaña **Settings** de tu repositorio en GitHub.
4. En la barra lateral izquierda, haz clic en **Pages**.
5. En la sección **Build and deployment**, bajo **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`, luego haz clic en **Save**.
6. En un par de minutos, GitHub te dará un enlace público (ej. `https://tu-usuario.github.io/ai-team-quiz/`) que podrás compartir con todo tu equipo para que jueguen directamente en su navegador.
